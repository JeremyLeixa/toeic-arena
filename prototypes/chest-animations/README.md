# Chest Animation Prototypes

Three standalone HTML prototypes exploring new directions for the chest opening animation in TOEIC Arena.

## How to test

1. Open each `.html` file directly in your browser (double-click, or right-click → Open With → Chrome/Firefox)
2. Use the rarity selector at the top to see how the animation adapts to Common / Uncommon / Rare / Epic / Legendary
3. Click "Replay" to play the animation again
4. Compare the three and tell me which direction you prefer (or a mix)

## The three directions

- **option-a-runic.html** — Runic Invocation. Magic circle draws itself under the chest, energy waves, vertical light beam. Very on-brand with the medieval fantasy DA.
- **option-b-tarot.html** — Tarot Flip. A decorative gold card floats in, flips in 3D to reveal the reward. Elegant, RPG-style.
- **option-c-boss-loot.html** — Boss Loot. Cinematic drama with zoom, explosion, beam of light, reward descending from above. AAA game vibe.

## Not deployed

These prototypes live outside the `src/` folder so they're not included in the Vercel build. They're only here for design exploration.
