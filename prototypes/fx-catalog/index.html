FX Catalog — effets de carte

Tout ce que je peux poser sur une .crd en CSS pur (zéro dépendance, marche sur mobile). Repère les IDs qui t'attirent — un skin se compose : 1 fond + (optionnel) 1 nappe de particules + (optionnel) 1 reflet + 1 bordure + (optionnel) 1 texture.

Ex. de commande : « FX-04 (fond) + FX-12 (particules) + FX-31 (bordure) » ou « la combo Frost mais en violet ». Note : ce que je ne peux pas faire en CSS pur = vraies particules physiques / fumée volumétrique / shaders 3D (ça demanderait du canvas/WebGL par carte — possible mais lourd, on en parle si besoin).
