Décisions de design à valider :
  • Position du bouton : sous l'exemple, avant les boutons SRS. Visible mais sans concurrencer le contenu principal.
  • Couleur de l'encadré FR : vert sourd (rappel « validation/aide »). Différent du gold/cyan principal — visuel « aide secondaire ».
  • Tag "FR" : petit chip vert pour signaler clairement le changement de langue, comme dans les grimoires.
  • Mémoire du choix ? Si l'étudiant ouvre la trad sur la carte 1, faut-il l'auto-ouvrir sur les suivantes de la session ? Mon avis : non — chaque carte est un nouveau test, on garde la friction « est-ce que je sais sans trad ? ».
  • Faux-amis : on pourrait ajouter un marqueur ⚠ dans le champ fr pour les faux-amis connus (eventually, actually, library, sensible…). À discuter si c'est généralisable.
