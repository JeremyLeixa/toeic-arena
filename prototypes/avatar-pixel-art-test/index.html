Décisions à valider en regardant ce rendu :
  • Lisibilité à 36 px (leaderboard) : la silhouette est-elle reconnaissable parmi les autres avatars ? Si oui → OK. Si trop floue → exiger plus de contraste sur la signature (cape/couronne plus saturée).
  • Crop circle vs square : laquelle préserve mieux l'identité de l'avatar ? Le carré arrondi garde plus de surface, le cercle est plus "moderne".
  • Pixelated vs anti-aliased : décoche la case pour voir le rendu flouté. Le pixel art DOIT rester pixelisé sinon il devient une bouillie.
  • L'épée à droite : avec object-fit:cover (par défaut), elle est coupée. Coche "object-fit:contain" pour voir l'image entière dans le carré — visuellement moins bon mais préserve le concept warrior.
  • Light mode : les tons dorés/jaunes se diluent-ils sur fond clair ? Si oui, prévoir un contour/halo sur l'avatar OU une bordure plus marquée.
